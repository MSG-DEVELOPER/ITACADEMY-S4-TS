# ITACADEMY-S4-TS


# 🎨 Proyecto: Practica de inicio con TypeScript y llamadasa a APIs.

## 📄 Descripción

En este proyecto, empezaremos a practicar con el superset TypeScript. Lo haremos con una práctica de llamadas a diferentes APIs que pondrán a prueva nuestro conocimiento de asincronía.

## 🚀 Aprendizajes
- Trabajo con TypeScript: Empezaremos a trabajar con TypeScript, un superconjunto de JavaScript que añade tipado estático y ayuda a evitar errores comunes.
- API Requests: Cómo hacer peticiones a APIs en JavaScript/TypeScript.
- Asincronía: Uso de async/await para gestionar las peticiones asíncronas de manera fácil y clara.



## 💻 Tecnologías Utilizadas

- TypeScript
- API Rest
- HTML/CSS
- Node.js



## 📋 Requisitos

- Node.js: Necesitarás tener Node.js instalado para poder ejecutar el proyecto.

- npm: Para gestionar las dependencias del proyecto.

## 🛠️ Instalación

1. Clona este repositorio
> https://github.com/MSG-DEVELOPER/ITACADEMY-S4-TS.git

2. Una vez dentro del directorio del proyecto, instala dependencias con
> npm install

3. Para ejecutar la aplicación, usa el siguiente comando:
> npm start

4. Ejecuta 
>npm run build 

para transpilar los archivos ts a js mediante un script
